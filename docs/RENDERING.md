# 3D rendering architecture

MoYoGarden 0.3 uses Three.js as a browser renderer while the authoritative
world simulation remains in the Cloudflare Worker and Durable Object.

## Asset pipeline

The browser loads four self-contained glTF 2.0 binary files from
`public/models/`. They are generated by `scripts/generate-models.mjs` during the build and served
as ordinary Cloudflare Static Assets. No model or
texture is downloaded from a third-party CDN at runtime.

Three.js itself is pinned in `package.json`. During `npm run build`,
`scripts/vendor-three.mjs` copies the required ES modules and the upstream MIT
license from `node_modules/three` into the generated `public/vendor/` directory.
That directory is deliberately ignored by Git.

## PBR and lighting

- glTF materials use the metallic-roughness workflow.
- Terrain, vegetation, low-detail fallbacks, and props use
  `MeshStandardMaterial`.
- Water uses `MeshPhysicalMaterial` with clearcoat and transmission.
- A `RoomEnvironment` PMREM supplies image-based lighting.
- ACES filmic tone mapping and sRGB output are enabled.
- A hemisphere light supplies broad ambient light.
- A directional sun casts soft PCF shadows onto terrain, buildings, resources,
  and residents.

## LOD policy

Each visible world object is a `THREE.LOD` instance.

| Object | High glTF | Medium | Far fallback |
|---|---:|---:|---:|
| Resident | 0–10 | 10–25 | 25+ |
| Resource | 0–13 | 13–28 | 28+ |
| Building | 0–18 | 18–39 | 39+ |

The medium glTF level hides small nodes marked `detail_*`. The far level uses a
small procedural mesh, reducing geometry and material work when viewing the
whole region.

## Camera controls

- Left drag: orbit
- Middle drag: grab and move the map
- Mouse wheel: zoom
- WASD: camera-relative movement

Middle-drag directions are intentionally the inverse of the previous release:
dragging the map right moves the view left, and dragging upward moves the view
backward, matching a grab-map interaction.

## Validation

`npm run build` performs TypeScript checking, vendors the pinned Three.js
runtime, checks browser JavaScript syntax, validates the import map and rendering
features, and parses every GLB header and PBR material declaration before
Wrangler deploys the Worker.
