# 3D rendering architecture

MoYoGarden 0.3.3 uses Three.js for the high-resolution preview while the authoritative world simulation remains in the Cloudflare Worker and Durable Object.

## Progressive startup

The renderer is split into non-blocking stages:

```text
classic boot watchdog
  → minified Three.js core
  → procedural LOD world (interactive)
  → API/WebSocket connection
  → bounded GLB queue
  → category-by-category model replacement
  → deferred shadows
  → deferred PMREM environment
```

The first interactive frame does not depend on GLTFLoader, RoomEnvironment, any GLB file, or the API. `boot.js` has a 12-second startup watchdog outside the ES module graph. If Three.js itself cannot load, the preview redirects to the stable renderer.

## Asset pipeline

The browser loads four self-contained glTF 2.0 binary files from `public/models/`:

- `settler.glb`
- `tree.glb`
- `rock.glb`
- `buildings.glb`

They are generated by `scripts/generate-models.mjs`. Each fetch and parse is bounded, GLB headers are checked before parsing, and at most two models load concurrently. A failed category keeps its procedural LOD fallback.

Three.js is pinned to `0.185.1`. The build copies the minified module runtime and only required add-ons to `public/vendor/three-r185/`. No runtime CDN is used.

## PBR and lighting

- glTF materials use metallic-roughness PBR.
- Terrain and fallbacks use `MeshStandardMaterial`.
- Water uses `MeshPhysicalMaterial` with clearcoat but no transmission pass.
- ACES filmic tone mapping and sRGB output are enabled.
- Hemisphere lighting is available on the first frame.
- `RoomEnvironment` and PMREM are imported and generated after interaction begins.
- Directional shadows are enabled after the first frame and update only when needed.

The shadow renderer uses `PCFShadowMap`; moving residents refresh the shadow map at a profile-dependent interval rather than every animation frame.

## LOD policy

Each object is a `THREE.LOD` instance. If a GLB is unavailable, the procedural model becomes level zero so objects remain visible.

| Object | High GLB | Medium GLB | Procedural far model |
|---|---:|---:|---:|
| Resident | 0–10 | 10–25 | 25+ |
| Resource | 0–13 | 13–28 | 28+ |
| Building | 0–18 | 18–39 | 39+ |

Distances are scaled by the selected quality profile. Medium GLB variants hide nodes marked `detail_*`.

## Camera controls

- Left drag: orbit
- Middle drag: grab and move the map
- Mouse wheel: zoom
- WASD: camera-relative movement

Middle-drag directions use grab-map behavior: moving the pointer right moves the camera left, and moving the pointer upward moves the camera backward.

## Preview isolation

The high-resolution branch deploys with `wrangler.pbr.jsonc` to `moyo-garden-pbr-preview`. It does not contain the production custom-domain route. The stable `main` Worker remains independent until the preview passes real-browser and Cloudflare verification.
